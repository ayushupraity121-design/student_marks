# Student Marks Analysis

## Approach
1. **Data Storage:** Stored student marks manually inside a standard Python list.
2. **Analysis:** 
   - Used `sum()` to calculate total marks.
   - Used `max()` and `min()` to find the highest and lowest scores.
   - Divided the total score by the length of the list (`len(marks)`) to find the average.
3. **Output:** Formatted and printed the metrics cleanly.
